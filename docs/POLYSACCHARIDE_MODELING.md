# 다당류 대표 fragment 모델링 기록

작성일: 2026-09-09. 대상: `AMYLOSE`, `AMYLOPECTIN`, `GLYCOGEN`, `CELLULOSE`.

이 문서는 앱이 다당류를 **전체 고분자가 아닌 대표 fragment**로 보여주는 이유, 그 fragment를
어떻게 만들었는지, 그리고 **화면의 모델을 실제 구조로 해석하면 안 되는 지점**을 기록합니다.
단당류·이당류의 검증은 [SCIENTIFIC_VALIDATION.md](SCIENTIFIC_VALIDATION.md)에 있습니다.

## 1. 왜 전체 고분자가 아니라 fragment인가

- 아밀로스·아밀로펙틴·글리코젠·셀룰로스는 모두 **분자량과 사슬 길이가 하나로 정해지지 않은**
  물질입니다. 시료·조직·생물종·추출 방법에 따라 달라집니다.
- 가지 다당류의 가지 개수와 간격, 사슬의 고차 구조(나선, 미세섬유, 결정 영역)도 하나의
  좌표 집합으로 확정할 수 없습니다.
- 따라서 "정확한 전체 분자 하나"를 파일로 배포하는 것은 과학적으로 틀린 표현이 됩니다.
- 대신 **결합 방식(어느 탄소끼리, α인지 β인지, 가지는 어디서 시작하는지)** 은 정확하게 정의되며,
  그것이 이 수업의 학습 목표입니다. 그래서 결합 구조는 정확하게, 길이와 가지 빈도는
  "대표"로 표시합니다.
- UI(`representationType: "fragment"`), 뷰어 태그(`대표 fragment`), 정보 패널 배지,
  `notes`, 그리고 이 문서에서 모두 같은 취지를 반복해 밝힙니다.

| 잔기 템플릿 β-Glcp | wwPDB CCD `BGC` idealized 좌표 (이 프로젝트가 이미 검증)                   | 셀룰로스                     |

원본 파일은 `public/molecules/references/`에 SHA-256과 함께 보존합니다. 취득은 개발 단계의
`npm run data:acquire`에서만 일어나고, 빌드와 배포본은 외부 API를 호출하지 않습니다.

**결합 길이·결합각·이면각 중 사람이 눈대중으로 정한 값은 없습니다.** 모든 junction은 위 참조
구조에서 측정한 값을 그대로 재현합니다.

### 왜 α(1→6)만 PubChem인가, 그리고 왜 결국 셋 다 PubChem인가

- CCD에는 isomaltose에 해당하는 단일 성분이 없습니다(구조 검색 결과 BIRD 참조 정의만 존재).
- 반면 CCD의 이당류 성분 `CBI`/`LAT`는 idealized 좌표에서 공여체 O5와 수용체 O3 사이 거리가
  **2.13 Å**로 측정됩니다. 두 원자는 공유 결합이 아니고 결합 그래프상 5 결합만큼 떨어진
  진짜 비결합 접촉이므로, 이 값은 unusually short nonbonded O···O contact입니다. 같은
  기하를 사슬 전체에 반복하면 이 접촉이 residue마다 누적됩니다.
- 같은 접촉이 PubChem 계산 conformer에서는 **2.81 Å**이고, 세 결합 모두 한 파이프라인에서
  나오므로 fragment의 junction 기하는 PubChem으로 통일했습니다. (여기서는 측정값만
  비교하며, 일반적인 O···O 거리의 기준값을 주장하지 않습니다.)
- 두 출처가 서로 다른 답을 주는 것은 아닙니다. 아래 표처럼 같은 conformational family에
  있습니다. 두 값 모두 `docs/structure-validation.json`에 기록합니다.

| 결합   | CCD 이당류 φ / ψ    | PubChem conformer φ / ψ | 사용처                        |
| ------ | ------------------- | ----------------------- | ----------------------------- |
| α(1→4) | +72.7° / +85.8° (MAL) | +86.3° / +88.7° (CID 439186) | fragment 조립에 PubChem 사용 |
| β(1→4) | −65.1° / +90.0° (CBI) | −59.2° / +118.7° (CID 439178) | fragment 조립에 PubChem 사용 |
| α(1→6) | 해당 성분 없음        | +54.6° / +180.0°, ω −61.2° (CID 439193) | fragment 조립에 사용         |

정의: φ = O5–C1–Ox–Cx, ψ = C1–Ox–Cx–C(x−1), ω = O5–C5–C6–O6(수용체).

## 3. 조립 방법

`scripts/glycans.py`의 `build_polymer`. 강체 변환만 사용합니다.

1. 참조 이당류에서 수용체의 국소 좌표계(1→4는 C3·C4·O4, 1→6은 C5·C6·O6)를 세우고,
   그 좌표계에서 본 **공여체 잔기의 배치 행렬**을 구합니다. 검증된 CCD 단당류 템플릿을
   참조 구조의 공여체 고리에 Kabsch 정합(반사 금지)해 얻습니다.
   - 템플릿↔참조 고리 RMSD: α(1→4) 0.032 Å, β(1→4) 0.038 Å, α(1→6) 0.032 Å.
2. 사슬을 따라 이 배치 행렬을 반복 적용합니다. 반복되는 강체 변환이므로 결과는 나선 대칭을
   가집니다. 가지에서는 α(1→6) 배치 행렬을 사용합니다.
3. 글리코시드 결합을 만들 때 공여체의 O1·HO1을, 수용체의 HO4(또는 HO6)를 제거합니다.
   다리 산소는 수용체의 O4/O6이며, 공여체 아노머 탄소의 배치는 손대지 않습니다.
4. 수소 위치만 MMFF94s로 이완합니다. 모든 무거운 원자에 강한 위치 구속을 걸어
   고리·junction·입체중심을 고정합니다. 실제 이동량은 무거운 원자 최대 **0.0003 Å**입니다.
5. 관성 주축으로 강체 회전만 적용해 화면에 놓습니다(반사 없음, det = +1 확인).

### α(1→6) 가지의 torsion 선택

α(1→6) 결합은 회전 가능한 이면각이 셋(φ, ψ, ω)이라 실제로 유연합니다. 강체로 붙인 가지가
backbone 나선과 겹치는 경우가 있어 다음과 같이 처리했습니다.

- φ는 **exo-anomeric 효과로 강하게 구속되는 각**이므로 isomaltose 참조값(+54.6°)을 그대로 씁니다.
- ψ와 ω는 **표준 staggered rotamer 집합**(ψ ∈ {180°, ±60°}, ω ∈ {−60°, +60°, 180°})에서
  겹침이 가장 적은 조합을 선택합니다.
- 실제 선택 결과는 두 fragment 모두 ψ = 180°(참조값과 동일), ω = +60°입니다. 참조
  isomaltose의 ω는 −61.2°이므로 ω만 다른 staggered 값으로 바뀐 셈입니다.
- **rotamer 이름(gg/gt/tg)은 쓰지 않습니다.** 그 명칭은 어떤 원자쌍을 기준으로 하느냐에
  따라 부호 해석이 달라지는데, 이 문서에서 인용할 수 있는 근거가 없기 때문입니다. 대신
  아래처럼 네 원자를 명시한 측정값만 기록합니다. 이 값은 "이 fragment에서 사용한
  representative α(1→6) rotamer"이며 특정 명명된 rotamer라고 주장하지 않습니다.
- 이 선택은 `docs/structure-validation.json`의 `branchTorsions`에 기록됩니다.

이면각의 정의는 다음 네 원자입니다(D = 공여체 잔기, A = 수용체 잔기, O6 = 다리 산소).

| 각 | 원자 순서 | isomaltose 참조 | 배포된 fragment |
| -- | --------- | --------------: | --------------: |
| φ  | D:O5 – D:C1 – O6 – A:C6 | +54.61° | +54.90° |
| ψ  | D:C1 – O6 – A:C6 – A:C5 | +180.00° | ±180.00° |
| ω  | A:O5 – A:C5 – A:C6 – O6 | −61.22° | +60.00° |
| (참고) | O6 – A:C6 – A:C5 – A:C4 | +59.53° | ±180.00° |

## 4. 각 fragment의 구성과 근거

| 화면        | residue 수 | 원자 수 | 결합 구성              | 가지 위치                                     |
| ----------- | ---------: | ------: | ---------------------- | --------------------------------------------- |
| Amylose     |         10 |     213 | α(1→4) × 9             | 없음                                          |
| Amylopectin |         12 |     255 | α(1→4) × 10, α(1→6) × 1 | 사슬 8개 중 한 곳에서 4-residue 가지            |
| Glycogen    |         16 |     339 | α(1→4) × 13, α(1→6) × 2 | 사슬에서 한 번, 그 가지 위에서 다시 한 번       |
| Cellulose   |          8 |     171 | β(1→4) × 7             | 없음                                          |

선택 이유:

- **길이**: 반복 결합이 만드는 사슬 모양이 눈에 보이려면 한 바퀴 이상이 필요합니다.
  아밀로스는 계산된 나선 주기(약 6.3 residue/turn)보다 길게 10개로 잡았습니다. 셀룰로스는
  거의 곧게 뻗어 residue당 약 4.95 Å 전진하므로 8개(약 35 Å)로 충분히 관찰됩니다.
  더 늘리면 화면에서 작아지고 원자 수만 늘어납니다.
- **가지 위치**: 사슬 중간에 두어야 "backbone에서 갈라져 나온다"는 점이 보입니다. 끝에 두면
  단순히 사슬이 길어진 것처럼 보입니다.
- **글리코젠의 가지 위의 가지**: 글리코젠과 아밀로펙틴은 결합의 종류가 같습니다. 차이는
  가지가 놓이는 층위와 빈도이므로, 가지 위에서 다시 갈라지는 구조를 하나 넣어
  "더 자주, 여러 층으로 갈라진다"는 점만 보이도록 했습니다.
- **아밀로펙틴 1곳 vs 글리코젠 2곳**은 상대적 경향을 보이기 위한 최소한의 대비이며
  정량적 비교가 아닙니다.

## 5. 무엇을 검증했나

`scripts/prepare_molecules.py` 실행 시 아래가 모두 assert로 강제되며, 결과는
`docs/structure-validation.json`에 저장됩니다. 자동 테스트(`tests/structures.test.ts`)도
배포되는 파일에서 다시 확인합니다.

- **고리**: 잔기 수와 같은 개수의 6원자 고리, 다른 고리 없음.
- **입체배치**: 각 잔기의 C2·C3·C4·C5에서 고정된 이웃 3개가 만드는 **부호 있는 부피**를
  계산해 검증된 단당류 템플릿과 부호를 대조합니다. R/S 문자는 이웃 OH가 글리코시드 결합으로
  바뀌면 CIP 우선순위가 바뀌어 원자가 움직이지 않아도 달라지므로 비교 기준으로 쓰지 않습니다.
  (예: 자유 α-D-glucose의 C3는 S이지만 maltose 환원 말단 잔기의 C3는 R입니다.)
- **아노머 배치**: 아노머 탄소에서 (고리 O, 고리 밖 O, 고리 이웃 C)가 만드는 부호 있는 부피를
  CCD `GLC`(α)/`BGC`(β)와 대조합니다. 고리 형태와 무관한 판정입니다.
- **연결**: 각 결합의 공여 아노머 탄소, 다리 산소, 수용 탄소가 실제 결합 그래프와 일치.
  다리 산소는 고리 밖 산소이며 정확히 두 탄소와만 결합.
- **junction 기하**: 모든 결합의 C–O 길이, C–O–C 각, φ, ψ를 참조 conformer와 대조.
  배포된 SDF 좌표에서 다시 측정한 재현 오차의 최댓값은 길이 **0.0023 Å**, C–O–C 각
  **0.484°**, φ **0.944°**, ψ **0.478°**입니다(α(1→6)의 ψ는 의도적으로 staggered 값으로
  바꾸므로 이 비교에서 제외).
- **겹침**: 두 가지 기준으로 검사합니다.
  - 직접 연결되지 않은 잔기 사이 무거운 원자 최소 거리: 아밀로스 4.72 Å, 셀룰로스 5.50 Å,
    아밀로펙틴·글리코젠 3.78 Å.
  - 결합 그래프상 3 결합 이상 떨어진(1-4 이상) 모든 원자쌍에 대해
    `d < 0.75 × (r_vdW,A + r_vdW,B)`(Bondi 반지름)를 severe overlap으로 정의한 검사.
    네 fragment 모두 해당 쌍이 **0개**이고, 최소 `d / (r_A + r_B)` 비는 0.813–0.820입니다.
    같은 기준의 무거운 원자 최소 거리는 2.76–2.80 Å입니다.
  - `structure-validation.json`의 `minimumNonBondedHeavyDistance`는 더 느슨한 기준
    (4 결합 이상 떨어진 쌍만)으로 계산한 값이라 2.85–2.91 Å로 나옵니다. 두 숫자는 같은
    구조를 서로 다른 제외 규칙으로 잰 것입니다.
- **직렬화 후 재확인**: 배포되는 SDF 바이트를 다시 읽어 좌표에서 입체배치를 재계산하고
  같은 결과가 나오는지 확인합니다.
- **반사 금지**: Kabsch 정합은 SVD의 부호 보정항 때문에 항상 det(R) = +1인 순수 회전을
  내놓습니다(구조적으로 반사가 불가능하며, 코드의 `assert det > 0.99`는 그 사실을 다시
  적어 둔 것입니다). 반사가 실제로 일어나지 않았다는 증거는 아래 §5.1의 독립 검사입니다.

### 5.1 배포 파일에 대한 독립 검사 (2026-09-09 감사)

생성기를 전혀 사용하지 않고, 배포되는 SDF만 다시 파싱해 확인했습니다.

- **in-silico 가수분해**: 각 fragment에서 잔기를 하나씩 잘라 내고, 공여했던 아노머 산소를
  다리 산소의 **원래 좌표 자리에** 되돌려 자유 단당류로 복원한 뒤 InChIKey를 계산했습니다.
  46개 잔기 전부가 기대한 단당류와 일치했습니다.
  - 아밀로스·아밀로펙틴·글리코젠의 모든 잔기 → `WQZGKKKJIJFFOK-DVKNGEFBSA-N` (CCD `GLC`)
  - 셀룰로스의 모든 잔기 → `WQZGKKKJIJFFOK-VFUOTHLCSA-N` (CCD `BGC`)
  - InChIKey의 입체 layer는 반사에 민감하므로, 이 결과는 반사가 없었다는 직접 증거이기도
    합니다.
- **단당류·이당류 10종**: 배포 SDF에서 RDKit이 계산한 InChI/InChIKey가 CCD CIF에 기록된
  값과 문자열까지 완전히 일치했습니다.
- **연결성**: 네 fragment 모두 disconnected fragment 0, 좌표가 겹치는 원자 0,
  zero-length 결합 0, 공유 결합 길이 0.971–1.532 Å.
- **분자식**: C60H102O51 / C72H122O61 / C96H162O81 / C48H82O41 로 (C₆H₁₀O₅)ₙ·H₂O와 일치.

fragment에서 측정한 나선 파라미터(참고값):

| 화면      | residue당 회전 | 한 바퀴 residue 수 | residue당 전진 |
| --------- | -------------: | -----------------: | -------------: |
| Amylose   |          56.9° |               6.33 |         4.00 Å |
| Cellulose |         130.4° |               2.76 |         4.95 Å |

이 값은 **화면에 있는 fragment의 기하학적 성질**이며, 실제 고분자가 항상 이 나선을 갖는다는
뜻이 아닙니다. 가지가 있는 fragment에는 반복 단위가 하나가 아니므로 계산하지 않습니다.

## 6. 실제 macromolecule과 화면 모델의 차이 (해석 금지 목록)

1. **길이**: 화면은 8–16개 residue입니다. 실제 아밀로스는 수백~수천, 아밀로펙틴과 글리코젠은
   수천~수만 개 규모입니다. 화면의 크기를 실제 크기로 읽으면 안 됩니다.
2. **가지 빈도**: 화면의 가지 1개(아밀로펙틴)와 2개(글리코젠)는 관찰을 위해 정한 값입니다.
   실제 평균 가지 빈도(글리코젠은 대략 8–12 residue마다 하나로 알려져 있습니다)를 재현하지
   않습니다. 두 조각의 가지 수를 정량 비교의 근거로 쓰면 안 됩니다.
3. **conformation**: 반복 강체 변환의 결과이므로 완전한 규칙 나선입니다. 실제 사슬은 용액에서
   결합 주위로 회전하며 여러 형태를 가지고, 고체에서는 결정 형태에 따라 달라집니다.
   "아밀로스 = 항상 하나의 나선", "셀룰로스 = 항상 완전한 직선"으로 읽으면 안 됩니다.
4. **에너지·안정성**: 어떤 형태가 더 안정한지 계산하지 않았습니다. 수소 위치 이완은
   MMFF94s를 썼지만 이는 O–H 방향만 정리한 것이고 conformational 에너지 비교가 아닙니다.
5. **고차 구조**: 셀룰로스 미세섬유, 녹말 알갱이, 글리코젠 입자(글리코제닌 중심의 β-particle)
   같은 상위 구조는 전혀 포함되어 있지 않습니다. 셀룰로스의 강도는 사슬 하나가 아니라 사슬
   사이 수소 결합과 이 상위 배열까지 보아야 설명됩니다.
6. **환원 말단**: 화면의 조각에는 환원 말단이 하나 있습니다. 실제 거대 분자에서도 분자당
   환원 말단은 하나지만, 조각의 말단은 "그 자리에서 잘렸다"는 뜻일 뿐 생체 내 사슬 말단과
   같지 않습니다. 비환원 말단의 개수도 조각의 크기에 따른 값입니다.
7. **녹말**: 녹말은 아밀로스와 아밀로펙틴을 함께 포함하는 물질입니다. 앱은 `STARCH`라는
   단일 분자 ID나 단일 SDF를 만들지 않고 두 성분을 각각 보여줍니다.

## 7. 재현 방법

```sh
npm run data:acquire                 # 원본 CIF/SDF 다시 내려받기 (개발 단계에서만)
python -m pip install --target .pydeps numpy rdkit
python scripts/prepare_molecules.py  # 검증 + SDF/metadata/검증 리포트 생성
npm test
```

`scripts/prepare_molecules.py`는 단당류 6종의 SDF를 바이트 단위로 동일하게 재생성합니다.
RDKit 2026.03.6, numpy 2.5.3에서 확인했습니다.
